Wavez Tools

Quality of life tools for wavez.fm

What Is This?

I've spent a lot of hours in the rooms and some small things kept turning up. Chat I couldn't collapse. Songs I wanted to search on Spotify. 3rd party images that wouldn't load in my region, thanks UK law. So I fixed them, one script at a time.

All code is open source, so you can see what you're installing.

Installing

  1. Get Tampermonkey (or any userscript manager).
  2. Click a script below. They self-update after that.

Get all scripts in one install

Toggle each feature from your userscript manager's menu.

Auto Woot, Auto Grab and Region Check start off by default.

Scripts

Or pick them individually.

  • TranslateTranslate chat, inline and customisable
  • Open in SpotifyFind the currently playing song on Spotify
  • Chat ToggleCollapsible rail, hide and show chat.
  • Imgur FixUnbreak Imgur. Routes the traffic through a proxy
  • Auto WootWoot everything automatically
  • Auto GrabAutomatically grab what you woot
  • Region CheckFlag playlist tracks blocked in your region Needs a YouTube API key

Discord Rich Presence

Share and display your current room, track and artist on Discord.

Installing is two part with a browser userscript and a local bridge.
