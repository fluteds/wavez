About the bundle

One install that carries most scripts inside it. Each feature gets a switch in your userscript manager's menu, and the page reloads when you flip one.

Auto Woot, Auto Grab and Region Check start switched off. The other six start on.

A red tag means a script needs setting up before it does anything. Every config option is in 05 Settings.

Install not working?

If clicking Install lands you on Tampermonkey's Script Installation page and nothing else happens, Chrome is blocking the install, not the script.

Open chrome://extensions, click Details on Tampermonkey and turn on Allow User Scripts.

No such toggle? Turn on Developer mode at the top right instead.

Reload the page and click Install again. Don't use Tampermonkey's "Try to install as script", that installs the install page itself and fails.
