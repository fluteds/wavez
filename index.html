WAVEZ TOOLS =========== Quality of life tools for wavez.fm. I've spent a lot of nights in the rooms and the same small annoyances kept turning up. Chat I couldn't collapse. Songs I wanted on Spotify. Images that wouldn't load in my region. So I fixed them, one script at a time. Nothing official. INSTALL ------- 1. Get Tampermonkey (or any userscript manager). 2. Click a script below. They self-update after that.
